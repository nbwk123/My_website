# 友链

友链不是随机收藏夹，而是我愿意长期关注、反复回访的内容来源。这里会放朋友的网站、喜欢的博客、工具文档和启发我的作品。

</section>

**收录标准：** 它应该能持续给我带来启发，或者帮助访客理解我关注的学习、设计和创作方向。
</section>
