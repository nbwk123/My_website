<div class="note-steps" markdown="1">

<section class="note-step" markdown="1">
### Background
If learning only stays at the level of having seen something, it fades quickly. COSTORY aims to turn learning into a personal knowledge asset.
</section>

<section class="note-step" markdown="1">
### Goal
Build a stable format for recording why I learned something, what I learned, how I practiced it, what problems appeared, and what judgment remains.
</section>

<section class="note-step" markdown="1">
### Process
Start from course notes and project records, break common information into reusable modules, then refine the page structure for long-term maintenance.
</section>

<section class="note-step" markdown="1">
### Next Step
Add real content, case images, and interaction notes so this grows from a template into a finished project page.
