# 个人网站系统

一个用 Vibe Coding 持续搭建和迭代的个人作品集系统。它不只是展示页面，而是把内容生产、设计判断、低代码维护和 GitHub 发布组织成一套可长期运行的流程。

</section>

<section class="note-callout" markdown="1">
**核心问题：** 对不擅长代码的人来说，个人网站最难的不是第一次做出来，而是之后能不能持续更新、调整结构、发布内容。
</section>

<div class="module-list" markdown="1">

<article class="module-row" markdown="1">
<span>GOAL 01</span>
<div markdown="1">
<strong>让作品集变成系统，而不是一次性页面。</strong>
<p>网站需要同时承载首页、课程笔记、项目案例、友链和关于信息，并在未来内容增加后仍然保持清晰结构。</p>
</div>
</article>

<article class="module-row" markdown="1">
<span>GOAL 02</span>
<div markdown="1">
<strong>让低代码用户也能维护内容。</strong>
<p>通过网站管理器把页面选择、内容编辑、模块插入、预览、构建和部署流程集中起来，减少直接修改代码的压力。</p>
</div>
</article>

<article class="module-row" markdown="1">
<span>GOAL 03</span>
<div markdown="1">
<strong>让 AI 协作有清晰判断标准。</strong>
<p>每次修改不只追求“看起来好看”，还要检查定位是否清楚、项目是否可读、交互是否必要、中英文是否一致。</p>
</div>
</article>

</div>

<section class="note-dark-panel" markdown="1">

## 方法

- 用 MkDocs 和 Material 搭建稳定的信息结构
- 用自定义 CSS 和 JavaScript 补充个人化视觉与交互
- 用中英文目录维护双语内容
- 用本地管理器降低日常编辑门槛
- 用 GitHub Pages 完成公开托管

</section>

管理器提供页面选择、新建页面、模块插入、预览、构建和部署入口，是后续低代码维护的基础。
