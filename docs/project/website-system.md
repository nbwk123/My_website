<div class="module-list" markdown="1">

<article class="module-row" markdown="1">
<span>GOAL 01</span>
<div markdown="1">
<strong>Turn the portfolio into a system, not a one-off page.</strong>
<p>The site needs to hold the homepage, course notes, project cases, links, and about information while staying clear as more content is added in the future.</p>
</div>
</article>

<article class="module-row" markdown="1">
<span>GOAL 02</span>
<div markdown="1">
<strong>Make content maintenance possible for low-code users.</strong>
<p>The website manager brings page selection, content editing, module insertion, preview, build, and deployment into one place, reducing the pressure of editing code directly.</p>
</div>
</article>

<article class="module-row" markdown="1">
<span>GOAL 03</span>
<div markdown="1">
<strong>Give AI collaboration clear judgment criteria.</strong>
<p>Each iteration is not only about making the page look better. It also checks whether the positioning is clear, projects are readable, interactions are necessary, and Chinese and English pages stay aligned.</p>
</div>
</article>

</div>

<section class="note-dark-panel" markdown="1">

## Method

- Build a stable information structure with MkDocs and Material
- Add personal visual style and interaction through custom CSS and JavaScript
- Maintain bilingual content with Chinese and English directories
- Use a local manager to lower the daily editing threshold
- Publish the site through GitHub Pages

</section>

## What Has Been Completed

<div class="note-steps" markdown="1">

<section class="note-step" markdown="1">
### Homepage Project Entry
The homepage uses a large headline, stacked project cards, and drag-to-switch interaction so visitors can see representative work immediately.
</section>

<section class="note-step" markdown="1">
### Modular Content
The course, project, links, and about pages use richer modules instead of plain Markdown paragraphs only.
</section>

<section class="note-step" markdown="1">
### Maintainable Features
Search, bilingual switching, light / dark / system color mode, and GitHub Pages publishing have been added.
</section>

<section class="note-step" markdown="1">
### Website Manager
The manager provides page selection, new page creation, module insertion, preview, build, and deployment actions as the basis for future low-code maintenance.
</section>

</div>
