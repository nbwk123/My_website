      Sample Note

      This is a reusable course note template. When adding future articles, copy this structure and replace the text with your own content.

      Course note Reusable template Work in progress

      Writing goal: Make a course note more than a record. It should help readers understand the topic, see your judgment, and know what to do next.

      Topic

      Describe the topic in one sentence and connect it to your long-term direction.

      • What problem does this note address?
      • How does it relate to interaction design, products, AI, or personal knowledge management?
      • What is the one idea readers should remember?

      Learning Goals

      Understand

      Explain the core concept in your own words instead of only copying source material.

      Practice

      Turn the idea into a small exercise, page, diagram, workflow, or reusable method.

      Reflect

      Record what you agree with, what you question, and where this knowledge may be useful.

      Extend

      Keep useful links, keywords, and follow-up questions for future research.

      References

      • Material for MkDocs documentation
      • Notion-style content organization
      • Add course links, papers, videos, tools, or examples here.

      Practice Steps

      Set the context

      Explain why this topic matters and how it connects to your current project.

      Break down concepts

      Turn source material into 3 to 5 key concepts, each with a concise explanation.

      Make a small output

      Use a diagram, code snippet, prototype, or case example to test your understanding.

      Summarize

      Write three to five sentences about the takeaway, open questions, and next step.

      Common Questions

      What if there is too much content?

      Keep the main thread first. Put details into references or follow-up questions so the page keeps a clear focus.

      What if I do not know how to summarize?

      Start with three prompts: what problem it solves, where you may use it, and what its limits are.

      Summary

      A good course note should feel like a refined knowledge card: clear topic, personal judgment, reading path, and useful references. The page does not need to be complex, but every module should have a clear reading purpose.
